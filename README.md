# EcoPlus
A frontend sustainability website built using HTML, CSS , Javascript

## 📌 Project Objective

The main goal of EcoPlus is to:
- Promote environmental awareness.
- Encourage sustainable daily habits.
- Help users estimate their carbon footprint.
- Inspire people to contribute towards a greener future.

## ✨ Features

- 🏠 Home page with an introduction to EcoPlus.
- 🌱 Eco Tips page containing simple sustainability practices.
- 🌍 Carbon Footprint Calculator.
- 📞 Contact page for user feedback and communication.
- 📱 Responsive design for different screen sizes.

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
